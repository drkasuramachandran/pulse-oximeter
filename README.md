# Pulse Oximeter

A simple web-based Pulse Oximeter interface developed using HTML, designed to display and visualize basic pulse oximetry parameters such as **SpO₂ (oxygen saturation)** and **heart rate (BPM)**.

## Features

* 🫁 SpO₂ (Blood Oxygen Saturation) display
* ❤️ Heart Rate / Pulse Rate display
* 📊 Simple and user-friendly interface
* 💻 Runs directly in a web browser
* 📱 Suitable for desktop and mobile viewing
* 🌐 Can be hosted using GitHub Pages

## About Pulse Oximetry

A pulse oximeter is a non-invasive device used to estimate:

* **SpO₂ (%)** – peripheral blood oxygen saturation
* **BPM** – heart rate or pulse rate in beats per minute

The device typically uses light absorption through a fingertip to estimate these parameters.
